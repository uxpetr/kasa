What lands in the pile

Every kind of content in a Kasa chat, how it looks on the table, and how it behaves.

Everything is an object
Each entry is one physical thing: paper, print, card. No bubbles, no bare text.
Chronological, always
Oldest at the top, newest at the bottom. Grouping and categories change layout and filtering, never order.
Same object everywhere
An item looks the same whether it came from the app, the extension or Telegram. Only the meta line says where.
One actions menu
Hover or long-press any object for Reply, React, Move to category, Star and Delete.
